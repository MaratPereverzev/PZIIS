Каталог для списка скомпрометированных паролей.

Положите сюда `weak-passwords.txt` (по одному паролю в строке) - например,
список top-10000 из публичных утечек. Файл в репозиторий не входит:
он большой и не является частью кода. Без него работает встроенный
минимальный список из `app/passwords.py`.
